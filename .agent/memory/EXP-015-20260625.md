# EXP-015 | MiMo Code instructions 字段格式

- **时间**: 2026-06-25 18:45
- **类别**: 环境
- **结论**: MiMo Code `mimocode.json` 的 `instructions` 字段必须是**数组格式**，不能是字符串
- **正确写法**:
  ```json
  "instructions": ["~/.agent-shared/AGENTS.md"]
  ```
- **错误写法**:
  ```json
  "instructions": "~/.agent-shared/AGENTS.md"
  ```
- **踩坑**: 字符串格式会导致启动报错，系统无法加载
- **来源**: MiMo Code 官网明确说明
- **行动**: 所有 Agent 工具配置前先查数据库/官网，不凭经验猜
