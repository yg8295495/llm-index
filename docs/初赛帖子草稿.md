## 1. Demo 简介

**是什么：** Web 端大模型选型决策工具
**面向谁：** 有具体工作任务需要接入大模型的职场人、关心预算的小团队和个人、想跟进新模型但没精力逐个关注的 AI 实践者

**核心功能：**

- **自定义权重排名** — 五大维度（事实准确、工作流、工程能力、成本、人类偏好）拖动权重，实时生成你的专属模型排名
- **200 模型矩阵热力图** — 一眼扫清各家模型在各维度的表现强弱，天花板在哪
- **多模型雷达图对比** — 选几个模型放在一起，维度差异一目了然
- **三套主题可选** — Apple Light / Gold Classic / Dark Pro，按你的审美切换
- **自定义方案保存** — 权重方案存本地，随时切换不同场景的选型逻辑

## 2. 创作思路

**灵感来源：**
大模型日新月异，活动频繁。一个模型虽然才中上游，但性能够用，而且最近按日限免——那不是选不选的问题，是必须选。但谁帮我盯着这些信息？

**想解决的问题：**
- 评测网站只回答"谁最强"，没人帮你回答"谁适合你"
- 某个新出的模型值不值得试？偏向哪方面？适合拿来干什么？答案散落在各处
- 平台号称聚合 N 个模型收月费，里面的模型到底好不好、按 token 计费到底花多少钱，算不清

**为什么做这个方向：**
市面上没有"按我的需求来排"的工具。这是我真实需要的，那就自己做一个，自由度最高。

## 踩坑与心得（加分项）

1. **AA 网站采集**：Next.js App Router 不使用 `__NEXT_DATA__`，数据在 RSC payload 的 8MB script 标签里，需要用 Python 多轮 unescape 才能解析
2. **CSS 类名冲突**：全局 `.empty` 选择器误匹配矩阵的 `.matrix-cell.empty`，改成 `main > .empty` 限定作用域
3. **heatmap 透明度**：`--accent-soft` 只有 8% 透明度在白色背景不可见，需要独立变量 `--accent-heatmap` 并调到 35%
4. **矩阵垂直居中**：固定行高 32px 的 grid 单元格必须用 `display:flex + align-items:center`，不能靠 padding 模拟
