# LLM-Index 前端设计规范

> 来源: awesome-design-md 提取 (Apple/Linear/Stripe/Notion/PostHog/Vercel)，结合项目特性裁剪
> 日期: 2026-06-19
> 适用: 信息聚合型数据看板，高信息密度，三主题

---

## 1. 表面层级（替代阴影的核心方法）

**核心原则**: 用 3-4 级表面色阶表达层级，卡片不用阴影。

| 层级 | Apple Light | Dark Pro | Gold Classic | 用途 |
|------|-------------|----------|--------------|------|
| L0 画布 | `#f5f5f7` | `#0d1117` | `#1a1714` | 页面背景 |
| L1 卡片 | `#ffffff` | `#161b22` | `#252019` | 卡片、面板、表格 |
| L2 悬浮 | `#fafafc` | `#1c2128` | `#2d2720` | hover态、选中态、强调面板 |
| L3 深层 | `#e8e8ed` | `#21262d` | `#352e26` | 表头、分割区、嵌套容器 |

- 卡片: 1px hairline 边框 + 无阴影
- 层级差 = 视觉信号，不需要 box-shadow

---

## 2. 排版

| 规则 | 值 | 说明 |
|------|-----|------|
| 数值列等宽数字 | `font-feature-settings: "tnum"` | 分数、排名、cost 等所有数值列必须启用 |
| 标题字重 | weight 600 | 不用 700/800 |
| 标题字间距 | display: -0.3 ~ -1px | 大标题负 tracking，正文 0 |
| 正文字重 | weight 400 | 不用 500 |
| 正文字号 | 15-16px | 信息密集区可用 14px |
| 正文行高 | 1.47-1.55 | 保证可读性 |

---

## 3. 色彩

### 强调色（每主题仅一个）

| 主题 | 强调色 | 用途 |
|------|--------|------|
| Apple Light | `#0066cc` (Action Blue) | 主CTA + 链接 + 焦点环 + 品牌标识 |
| Dark Pro | `#58a6ff` | 同上 |
| Gold Classic | `#d4a853` | 同上 |

- 强调色不做大面积填充，仅用于交互元素
- 不用纯黑 `#000000` 做正文色
- 不用纯白 `#ffffff` 做画布（仅做卡片表面）

### 文字色阶（4级）

| 层级 | Apple Light | Dark Pro | Gold Classic | 用途 |
|------|-------------|----------|--------------|------|
| 主文字 | `#1d1d1f` | `#e6edf3` | `#e8dcc8` | 标题、正文 |
| 次要 | `#333333` | `#b1bac4` | `#c4b89e` | 副标题、辅助说明 |
| 辅助 | `#7a7a7a` | `#7d8590` | `#8a7e68` | 标签、时间戳 |
| 禁用 | `#b0b0b0` | `#484f58` | `#5c5344` | 最弱信息、placeholder |

## 4. 圆角

| 元素 | 圆角 | 说明 |
|------|------|------|
| 卡片 | 12px | 统一 |
| 按钮 | 6-8px | 矩形，非药丸 |
| 主CTA | 9999px | 药丸形，仅主操作按钮 |
| 标签/Chip | 9999px | 药丸形 |
| 输入框 | 6-8px | 与按钮一致 |

## 5. 边框

| 主题 | Hairline | Hairline Soft | 用途 |
|------|----------|---------------|------|
| Apple Light | `#e0e0e0` | `#f0f0f0` | 卡片边框 / 行间线 |
| Dark Pro | `#30363d` | `#21262d` | 同上 |
| Gold Classic | `#3d3529` | `#2d2720` | 同上 |

---

## 6. 数据展示

- 排行榜/矩阵数值列: 必须启用 `tnum`
- 表头: 用 L2/L3 表面色背景区分，不用加粗边框
- 行间: 1px hairline-soft 细线，不用粗边框
- 信息密集区: 段间距 12px（vs 营销区 24px）

---

## 7. 间距

| 用途 | 值 |
|------|-----|
| 基础单位 | 4-8px |
| 卡片内边距 | 24px |
| 强调卡片内边距 | 32px |
| 区块间距 | 64-80px |
| 卡片间距 | 16-24px |
| 行内元素间距 | 8-12px |

---

## 8. 暗色主题补充

- 画布不用纯黑（Dark Pro 用 `#0d1117`，微蓝调）
- 4 级表面阶梯，每级差 ~5%
- 文字用亮灰不用纯白（纯白仅主标题）
- 强调色在暗面上更亮（如 Apple Sky Blue `#2997ff` 替代 Action Blue）
